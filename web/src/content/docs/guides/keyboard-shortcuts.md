---
title: "Keyboard Shortcuts"
---

This page summarizes the keyboard shortcuts. On macOS, `Cmd` takes the place
of `Ctrl`, except in `Ctrl+Tab`, which stays `Ctrl` (`Cmd+Tab` belongs to the
system).

## General

| Action | Shortcut |
|---|---|
| Open settings | `Ctrl+,` |
| Open search | `Ctrl+F` |
| Open reminders overview | `Ctrl+Shift+R` |
| Switch between areas | `Tab` / `Shift+Tab` |
| Jump between regions: sidebar, the active view's button, backlog, the view | `F6` / `Shift+F6`, `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Select / open / edit | `Enter` |
| Close dialog or menu | `Esc` |
| Open context menu | `Application key` / `Shift+F10` |

## Events and tasks

| Action | Shortcut |
|---|---|
| Quick add event | `Ctrl+N` |
| New event (full form) | `Ctrl+Shift+N` |
| Quick add task | `Alt+N` |
| New task (full form) | `Alt+Shift+N` |
| Import a calendar file | `Ctrl+O` |
| Edit entry | `Enter` |
| Check off / reopen task | `Space` |
| Delete entry | `Delete` |
| Move or copy to another calendar or list (day, agenda and task view) | `Shift+M` |
| Duplicate entry; on a series, the whole series (day, agenda and task view) | `Ctrl+D` |

## Contacts

| Action | Shortcut |
|---|---|
| Edit contact | `Enter` |
| Add contact | `Insert` |
| Delete contact | `Delete` |
| The contact's context menu | `Menu key` / `Shift+F10` |

Deleting asks first. In a read-only address book — a global address list, say
— the command is not offered: those entries belong to the provider.

## Views and navigation

| Action | Shortcut |
|---|---|
| Show today | `Ctrl+T` |
| Previous / next period | `Ctrl+←` / `Ctrl+→` |
| Previous / next period in the week and month grids | `Page Up` / `Page Down` |
| Move within view/list | `Arrow keys` |
| Week view: the same day one week earlier or later | `↑` / `↓` |
| Switch view: day, week, month, year, agenda, tasks, contacts | `Ctrl+1`–`Ctrl+7` |
| Say the calendar week and its days (day, week, month, year and agenda view) | `K` |
