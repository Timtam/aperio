---
title: "Tastaturkürzel"
---

Diese Seite fasst die Tastenkürzel zusammen. Unter macOS steht `Cmd` an der
Stelle von `Strg`.

## Allgemein

| Aktion | Kürzel |
|---|---|
| Einstellungen öffnen | `Strg+,` |
| Suche öffnen | `Strg+F` |
| Erinnerungs-Übersicht öffnen | `Strg+Umschalt+R` |
| Zwischen Bereichen wechseln | `Tab` / `Umschalt+Tab` |
| Zwischen den Hauptbereichen springen: Seitenleiste, Schaltfläche der aktiven Ansicht, Backlog, die Ansicht | `F6` / `Umschalt+F6`, `Strg+Tab` / `Strg+Umschalt+Tab` |
| Auswählen / öffnen / bearbeiten | `Eingabe` |
| Dialog oder Menü schließen | `Esc` |
| Kontextmenü öffnen | `Anwendungstaste` / `Umschalt+F10` |

## Termine und Aufgaben

| Aktion | Kürzel |
|---|---|
| Termin schnell anlegen | `Strg+N` |
| Neuer Termin (volles Formular) | `Strg+Umschalt+N` |
| Aufgabe schnell anlegen | `Alt+N` |
| Neue Aufgabe (volles Formular) | `Alt+Umschalt+N` |
| Kalenderdatei importieren | `Strg+O` |
| Eintrag bearbeiten | `Eingabe` |
| Aufgabe abhaken / wieder öffnen | `Leertaste` |
| Eintrag löschen | `Entf` |
| In einen anderen Kalender oder eine andere Liste verschieben oder kopieren (Tages-, Agenda- und Aufgabenansicht) | `Umschalt+M` |
| Eintrag duplizieren, bei einer Serie die ganze Serie (Tages-, Agenda- und Aufgabenansicht) | `Strg+D` |

## Kontakte

| Aktion | Kürzel |
|---|---|
| Kontakt bearbeiten | `Eingabe` |
| Kontakt anlegen | `Einfg` |
| Kontakt löschen | `Entf` |
| Kontextmenü des Kontakts | `Anwendungstaste` / `Umschalt+F10` |

Löschen fragt vorher nach. In schreibgeschützten Adressbüchern – einer
globalen Adressliste etwa – gibt es den Befehl nicht: dort gehören die
Einträge dem Anbieter.

## Ansichten und Navigation

| Aktion | Kürzel |
|---|---|
| Heute anzeigen | `Strg+T` |
| Voriger / nächster Zeitraum | `Strg+←` / `Strg+→` |
| Voriger / nächster Zeitraum im Wochen- und Monatsraster | `Bild auf` / `Bild ab` |
| In Ansicht/Liste bewegen | `Pfeiltasten` |
| Wochenansicht: derselbe Tag eine Woche früher oder später | `↑` / `↓` |
| Ansicht wechseln: Tag, Woche, Monat, Jahr, Agenda, Aufgaben, Kontakte | `Strg+1`–`Strg+7` |
| Kalenderwoche mit ihren Tagen ansagen (Tages-, Wochen-, Monats-, Jahres- und Agendaansicht) | `K` |
