---
title: "Tastaturkürzel"
---

Diese Seite fasst die Standard-Tastenkürzel zusammen. Die tatsächliche
Belegung kann je nach Plattform und deinen Anpassungen abweichen –
maßgeblich ist immer deine eigene Konfiguration unter **Einstellungen →
Tastaturkürzel**, wo du jedes Kürzel ändern kannst.

## Allgemein

| Aktion | Kürzel |
|---|---|
| Einstellungen öffnen | `Strg+,` |
| Suche öffnen | `Strg+F` |
| Erinnerungs-Übersicht öffnen | `Strg+Umschalt+R` |
| Zwischen Bereichen wechseln | `Tab` / `Umschalt+Tab` |
| Auswählen / öffnen / bearbeiten | `Eingabe` |
| Dialog oder Menü schließen | `Esc` |
| Kontextmenü öffnen | `Anwendungstaste` / `Umschalt+F10` |

## Termine und Aufgaben

| Aktion | Kürzel |
|---|---|
| Termin schnell anlegen | `Strg+N` |
| Neuer Termin (volles Formular) | `Strg+Umschalt+N` |
| Aufgabe schnell anlegen | `Alt+N` |
| Neue Aufgabe (volles Formular) | `Alt+Umschalt+N` |
| Eintrag bearbeiten | `Eingabe` |
| Aufgabe abhaken / wieder öffnen | `Leertaste` |
| Eintrag löschen | `Entf` |

## Kontakte

| Aktion | Kürzel |
|---|---|
| Kontakt bearbeiten | `Eingabe` |
| Kontakt anlegen | `Einfg` |
| Kontakt löschen | `Entf` |
| Kontextmenü des Kontakts | `Anwendungstaste` / `Umschalt+F10` |

Löschen fragt vorher nach. In schreibgeschützten Adressbüchern – einer
globalen Adressliste etwa – gibt es den Befehl nicht: dort gehören die
Einträge dem Anbieter.

## Ansichten und Navigation

| Aktion | Kürzel |
|---|---|
| Heute anzeigen | `T` |
| Voriger Zeitraum | `Bild auf` |
| Nächster Zeitraum | `Bild ab` |
| In Ansicht/Liste bewegen | `Pfeiltasten` |
| Ansicht wechseln | `1`–`7` (sofern belegt) |

## Anpassen

Unter **Einstellungen → Tastaturkürzel** kannst du jede Aktion mit einer
eigenen Tastenkombination belegen. Bereits vergebene Kombinationen werden
als Konflikt angezeigt, sodass du keine versehentlichen Doppelbelegungen
anlegst.

> **Screenreader-Hinweis:** Die Kürzel-Liste in den Einstellungen ist als
> Tabelle bzw. Liste ausgezeichnet und lässt sich Zeile für Zeile vorlesen.
> So kannst du dir jederzeit die aktuelle Belegung ansagen lassen.
