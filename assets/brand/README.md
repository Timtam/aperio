# Aperio brand icons

Upload-ready copies of the app icon, for the places that ask for one but are
not part of a build: OAuth provider consoles (Webex, Zoom, Google Cloud, the
Microsoft Entra portal), app directories, issue templates, press.

Nothing in the app reads these files. The build-time assets live elsewhere and
are listed at the bottom.

## Which file do I upload?

| File | Use it when |
|---|---|
| `aperio-icon-512.png` | **The default.** 512×512, logo on the brand background. This is what OAuth consoles want. |
| `aperio-icon-256.png` | The console caps the size below 512. |
| `aperio-icon-1024.png` | The console wants 1024, or you need a master to resize from. |
| `aperio-icon-512-transparent.png` | The console explicitly asks for transparency, or composites the icon onto its own tile. |

The background is `#E6F4FE`, the same value as `expo.android.adaptiveIcon.backgroundColor`
in `mobile/app.json`. The logo occupies the middle 72 %, leaving a margin that
survives the circular and squircle masks platforms apply.

## Where these come from

All four are derived from `mobile/assets/android-icon-foreground.png` — the
logo alone on transparency, which is the one clean source of the mark in this
repo. The derivation is: crop to the logo's bounding box, scale to 72 % of the
canvas, centre, composite onto the background.

Do not derive new icons from `mobile/assets/icon.png` or from the Tauri set;
those are outputs, not sources. If the mark itself changes, replace
`android-icon-foreground.png` first and regenerate everything from it.

## The build-time assets (do not upload these)

- `mobile/assets/icon.png` — iOS / general app icon, 1024×1024, no alpha channel
  (iOS rejects an app icon that has one).
- `mobile/assets/android-icon-{foreground,background,monochrome}.png` — the three
  Android adaptive-icon layers. Background is a flat colour plate on purpose.
- `mobile/assets/splash-icon.png` — logo on transparency; it sits on the
  `backgroundColor` configured for `expo-splash-screen` in `mobile/app.json`,
  which has a light and a dark variant.
- `mobile/assets/favicon.png` — 48×48, Expo web.
- `src-tauri/icons/` — the desktop bundle set, generated by
  `npx tauri icon assets/brand/aperio-icon-1024.png` and referenced from
  `bundle.icon` in `src-tauri/tauri.conf.json`.
- `web/public/favicon.svg` — the documentation site.
